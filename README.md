# Política de privacidade do Sibito

Este repositório contém a política de privacidade do aplicativo Sibito, em HTML e texto simples.

## Publicar com GitHub Pages

1. No GitHub, abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
4. Aguarde o GitHub Pages publicar o site. A página será disponibilizada em `https://adalbertomaranhao.github.io/politica-de-privacidade-sibito/`.
5. Abra o endereço em uma janela privada para confirmar que está público e informe essa URL no campo de política de privacidade do Google Play Console.
